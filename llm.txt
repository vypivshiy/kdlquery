# kdlquery

> A pure Python KDL 2.0 parser with a CSS3-like selector API.

## Overview

kdlquery provides five main capabilities:

1. **Lossless CST parser** (`kdlquery.parser`) — Lexer + recursive-descent parser producing a typed CST with full source spans. Conforms to KDL 2.0 spec.
2. **Node tree** (`kdlquery.document`) — `KdlDocument` with `KdlNode` objects that carry their own `parent` references. Navigation methods delegate to nodes. Containers are mutable (`list` / `dict`) to support tree editing.
3. **Reader API** (`kdlquery.reader`) — Walk the node tree and transform it into arbitrary Python objects via the `Reader` abstract class. Includes `Walker`, `WalkContext`, diagnostic collection, and `parse_into()` convenience function. `DictReader` (`kdlquery.dict_reader`) produces nested dicts.
4. **Selector engine** (`kdlquery.selector`) — CSS3-like selectors for querying nodes by name, type annotation, properties, arguments, combinators, and pseudo-classes. Works on both `KdlDocument` (full tree) and `KdlNode` (children subtree only). Lexer → parser → matcher pipeline with LRU-cached selector parsing. `MatchContext` Protocol decouples the matcher from the document.
5. **Serializer** (`kdlquery.serializer`) — Emit KDL 2.0 text from any `KdlDocument` / `KdlNode` / `KdlValue` via their `to_kdl()` methods. Spec-compliant: bare identifier detection (§3.10), quoted string escapes (`\\ \" \n \r \t \b \f \u{XXXX}`), multi-line dedent, `#true`/`#false`/`#null`/`#inf`/`#nan` keyword numbers, type annotations.

## Quick start

```python
from kdlquery import parse

doc = parse('''
app "my-service" version="1.0.0" {
    server "primary" port=8080 tls=#true
    server "replica" port=8081 tls=#false
}
''')

doc.select("server[tls=#true]")    # → [server "primary"]
doc.select_one("app")              # → app node
doc.parent_of(doc.nodes[0].children[0])  # → app node

# Navigation directly on nodes
app = doc.nodes[0]
app.children[0].parent is app      # True
app.children[0].depth()            # 1
app.children[0].root is app        # True

# Parent queries
host = doc.select_one("host")
host.parents()                     # [server, app]
host.closest("server")             # server node
host.matches("host")               # True

# Node selectors — scoped to children subtree
app.select("server > host")        # → [host "localhost", host "127.0.0.1"]
app.select("*:root")               # → [] (no root concept in subtree)

# Mutation + serialization
from kdlquery import KdlNode, KdlValue
app.add_child(KdlNode.create("footer", args=[KdlValue.create(True)]))
app.set_prop("migrated", KdlValue.create(True))
doc.to_kdl()                       # → KDL 2.0 text with trailing newline
app.to_kdl(indent_str="\t")        # → custom indent
```

## Public API surface

### Entry points

- `parse(source: str) -> KdlDocument` — Parse KDL 2.0 string into queryable document tree.
- `parse_into(document: CSTDocument, reader: Reader, *, strict=False) -> tuple[R, list[ReadDiagnostic]]` — Walk CST through a Reader.

### Key types

- **KdlDocument** — Owns the node tree; provides `select()`, `select_one()`, `parent_of()`, `depth_of()`, `index_of()`, `siblings_of()`, `iter_nodes()`. Mutation: `add_node()`, `insert_node()`, `remove_node()`. Serialization: `to_kdl(indent_str="    ") -> str` (trailing newline; empty doc → `""`).
- **KdlNode** — Mutable node with `name`, `type_annotation`, `args` (list), `properties` (dict), `children` (list), `span`, `parent`. Methods:
  - Value access: `get_arg(i)`, `get_prop(k)`, `has_prop(k)`, `iter_args()`, `iter_props()`
  - Mutation: `create(name, *, args=, properties=, children=, type_annotation=)` (classmethod factory), `add_child()`, `insert_child(i,)`, `remove_child(i)`, `add_arg()`, `set_prop(k,)`, `remove_prop(k)`
  - Selector queries: `select(selector)`, `select_one(selector)` — scoped to descendants, cannot access parent or root nodes.
  - Navigation (DOM-like): `root` (property), `document` (property), `depth()`, `index()`, `siblings()`, `iter_descendants()`, `parents()`, `matches(selector)`, `closest(selector)`
  - Serialization: `to_kdl(*, indent=0, indent_str="    ", force_children_block=False) -> str`
- **KdlValue** — Frozen typed value with `value`, `span`, `type_annotation`. Factories: `create(value, type_annotation=None)` (Python primitive → inferred KDL literal), `keyword(raw)` (raw passthrough wrapped in `_Keyword` sentinel). Serialization: `to_kdl(*, indent=0, indent_str="    ") -> str`.
- **Reader[T_node, R]** — ABC with `on_node()`, `error_node()`, `finalize()`.
- **DictReader** — Built-in reader producing `Node` TypedDicts.
- **SelectorError** — Raised on invalid selector syntax.

### CST types (low-level)

- `KDL2CSTParser().parse(source) -> CSTDocument`
- `KDLLexer(source).tokenize() -> list[Token]`
- `CSTDocument`, `CSTNode`, `CSTValue`, `CSTArgEntry`, `CSTPropEntry`, `CSTTypeAnnotation`, `CSTIdentifier`

## Selector syntax

```
# Node
name                    by name
*                       any node
(type)                  by type annotation
(type)name              type annotation + name

# Property filters
[key]                   exists
[key=val]               equals
[key^=val]              starts with
[key$=val]              ends with
[key~=val]              contains
[(type)key]             property with type-annotated value
[(type)key=val]         type-annotated + value match

# Argument filters
[N]                     argument at position N exists
[N=val]                 equals
[N^=val]                starts with
[N$=val]                ends with
[N~=val]                contains
[(type)N]               argument with type annotation
[*=val]                 any argument equals val

# Combinators
A B                     descendant
A > B                   direct child
A + B                   adjacent sibling
A ~ B                   general sibling
A, B                    union (deduplicated)

# Pseudo-classes
:root
:first-child
:last-child
:nth-child(n)
:nth-child(2n)
:nth-child(2n+1)
:only-child
:empty
:not(compound)
:has(complex)
:has(> complex)
```

## Reader pattern

Subclass `Reader[T_node, R]` to transform the tree:

```python
class MyReader(Reader[dict, dict]):
    def on_node(self, node: KdlNode, ctx: WalkContext[dict]) -> dict:
        children = ctx.walk_children()
        return {"name": node.name, "children": children}

    def error_node(self, node, message, ctx):
        return {"name": node.name, "error": message}

    def finalize(self, nodes, diagnostics):
        return nodes
```

## Parse error codes

`KDLParseError` carries a stable machine-readable `code` (keyword-only, defaults to `""` for backward compatibility) and a human-readable `hint` looked up from a central table. Downstream tools should branch on `code`, not on `msg` text.

```python
from kdlquery import parse, KDLParseError, PARSE_ERROR_CODES

try:
    parse(r'foo re #"(\d+)"')          # missing trailing #
except KDLParseError as e:
    e.code   # "raw-string/unterminated"
    e.hint   # actionable, non-empty string
    e.msg    # "Unterminated raw string"
    e.line   # 1
    e.col    # 7
```

`PARSE_ERROR_CODES` is a `frozenset[str]` of all category codes — useful for self-doc and exhaustiveness checks.

Codes are path-like, lowercase-kebab, and extensible. Adding a new category = one row in `_PARSE_ERROR_HINTS` (`kdlquery/types.py`) + one `code="..."` emit site in the parser.

| code | hint (summary) |
|------|----------------|
| `raw-string/unterminated` | KDL raw strings need a matching trailing `#` per leading `#` |
| `raw-string/newline` | single-line raw strings cannot span lines |
| `multiline-raw-string/no-leading-newline` | multiline raw body must start with `\n` after opening delimiter |
| `multiline-raw-string/decode` | multiline raw body violates KDL2 indent/escape rules |
| `quoted-string/unterminated` | quoted string missing closing `"` |
| `quoted-string/newline` | quoted strings cannot contain a literal newline |
| `quoted-string/decode` | invalid escape sequence in quoted string |
| `multiline-string/no-leading-newline` | multiline string body must start with `\n` after opening `"""` |
| `multiline-string/unterminated` | multiline string missing closing `"""` |
| `multiline-string/decode` | multiline string body violates KDL2 indent/escape rules |
| `block-comment/unterminated` | `/* ... */` missing closing `*/` |
| `unexpected-character` | character not valid in KDL2 at this position |
| `bom-outside-start` | U+FEFF only permitted as first code point |
| `surrogate-codepoint` | lone UTF-16 surrogates not allowed |
| `control-codepoint` | C0/C1 control chars (except tab/newline) not allowed |
| `direction-control-codepoint` | bidi control chars not allowed |
| `number/invalid-trailing` | number literal followed by identifier char without delimiter |
| `reserved-bare-identifier` | reserved identifier (`true`/`false`/`null`/`inf`/`nan`/`-inf`) not valid as bare ident |
| `children-block/unterminated` | `{ ... }` missing closing `}` |
| `node/multiple-children-blocks` | a node may have at most one children block |
| `expected-eol` | expected newline / semicolon / EOF after node |
| `expected-whitespace` | KDL2 requires whitespace between entries |
| `slashdash/no-children-block` | trailing `/` must be followed by a children block |
| `expected-identifier` | expected an identifier at this position |
| `expected-value` | expected a value (string/number/bool/null) at this position |
| `expected-token` | unexpected token — parser expected a specific token |

## Conventions
- `KdlValue` is frozen (immutable); constructed via `KdlValue.create()` or `KdlValue.keyword()`.
- `KdlNode` is mutable. `args` and `children` are `list[KdlValue]` / `list[KdlNode]`; `properties` is `dict[str, KdlValue]`. `KdlDocument.nodes` is `list[KdlNode]`.
- Mutators (`add_child`, `insert_child`, `add_node`, etc.) wire `parent` and `_document` back-references on inserted subtrees automatically.
- `_EMPTY_SPAN` (sentinel) is the default span for synthetic nodes/values produced via `create()`/`KdlNode.create()`.
- Source spans (`Span(start=Position, end=Position)`) on every CST node and high-level node.
- Selector parsing is cached with `functools.lru_cache`.
- KDL 2.0 spec features: slashdash comments, esclines, multiline strings, raw strings, type annotations, unicode whitespace.
- Serializer is spec-compliant but not byte-identical round-trip: comments (`//`, `/* */`, `/-`), raw-string variants, hex/octal/binary number formats, BOM, and version markers are normalized away.
